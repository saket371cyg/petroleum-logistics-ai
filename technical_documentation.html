Technical Documentation: Petroleum Decision Engine

1. The Technology Stack

  • Backend: FastAPI (High-performance API)
  • Database: PostgreSQL/SQLite via SQLAlchemy
  • ML/Forecasting: Scikit-Learn (RandomForestRegressor)
  • Optimization: NumPy (Vectorized cost math)
  • Frontend: React + Vite (Dynamic Dashboard)
  • Infrastructure: Docker (Containerization)

2. Logic Breakdown

Demand Forecasting (ML)

Using RandomForestRegressor to predict daily demand. Features include historical lag (t-1, t-2, t-7, t-14) and calendar data (month, day-of-week).

Dispatch Optimization (Hill Climbing)

A non-deterministic approach to find high-quality dispatch plans. It iterates through tanker/driver/slot combinations to minimize a cost function involving delivery time, idle time, and penalties.

Multi-Agent Orchestration

The system comprises 10 independent agents, each with a single responsibility. This architecture allows for deterministic rule-checking (e.g., Compliance Agent) to coexist with probabilistic forecasting (Demand Agent).

Route Search

A-Star (A*) algorithm is implemented to calculate path costs across a synthetic road graph, providing the optimization engine with realistic ETA/Risk inputs.

3. Faculty Key Takeaways

Emphasize modularity and testability. Mention that the system is LLM-agnostic—the intelligence is rooted in your agents and algorithms, not just calling a third-party API.
