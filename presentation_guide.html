B.Tech 3rd Year • AI Project Briefing

Petroleum Logistics Decision Intelligence Engine

A Multi-Agent System for Demand Forecasting, Optimization, and Supply Chain Resiliency.

The Technical Thesis

This project transitions from simple data visualization to Active Decision Support. It models a petroleum dealer's operational environment using a Multi-Agent System (MAS), where each agent handles a specific domain constraint (Compliance, Maintenance, Fleet, Inventory) to solve a unified logistics problem.

ML Demand Forecasting

Random Forest Regressor trained on historical sales, lag features (1/3/7/14 days), and temporal signals (weekends/holidays).

Optimization Dispatch Scheduling

Random-Restart Hill Climbing to solve the combinatorial problem of tanker-driver-slot assignment under cost and time constraints.

Agentic AI Multi-Agent System

10 specialized agents collaborating via a Logic-Engine to ensure all operational decisions are compliant and safe.

Potential Viva Questions
Q: Why use Hill Climbing instead of just sorting available tankers?
Sorting ignores the interdependencies. A tanker might be available, but the driver assigned to it might be nearing their shift limit, or the loading slot might be too late to prevent a stock-out. Hill Climbing evaluates the state as a whole.
Q: What makes this an "Agentic" system?
The system is Decentralized. The Compliance Agent doesn't know about sales; it only knows about licenses. The Executive Agent doesn't know about optimization; it orchestrates the output. This modularity allows for "Veto" logic and specialized domain intelligence.
Q: Why not use a Deep Learning model for forecasting?
For daily retail sales with limited history (~1-2 years), Random Forest/XGBoost is superior as it doesn't overfit like an LSTM might, and it provides better Feature Importance metrics which are crucial for business trust.

Key Algorithms Implemented

  • A* and Dijkstra: For route search between dealer and refinery, factoring in synthetic traffic/weather costs.
  • Hill Climbing: For the dispatch "neighborhood search," with random restarts to avoid local minima.
  • Logic-Based Intent Routing: For the AI Assistant, ensuring queries are routed to the correct agent for data retrieval.
